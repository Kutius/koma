# Koma 演进路线图（Roadmap）

> **一帧清光，恰如其分。**
> 本文档记录 **Koma** 的产品演进方向、版本里程碑与明确边界，用于指导后续版本迭代与架构演进。

---

## 1. 产品原则与护栏

任何新特性在进入路线图前，都必须同时满足以下约束：

1. **原位优先，少切窗口**：高频操作（框选、标注、取色、测距、长截图、取字、复制）尽可能在桌面遮罩原位一步完成，无需强制跳回主窗口。
2. **轻量与静置克制**：严守单文件原生（纯 Go + MyGo / Direct3D 11，零 CGO、零 WebView），每项能力上线前必须评估对**托盘静置内存、首次唤起延迟、峰值显存与安装包体积**的影响（详见 [性能与内存维护指南](performance.md)）。
3. **克制的 Liquid Glass 视觉语言**：让布局与微动效自己说话，不堆砌说明性横幅、引导条或低频装饰面板，保持全量无障碍标签与简洁 Tooltip。
4. **零摩擦的 Windows 原生体验**：优先复用系统原生能力（DWM、WinRT、Per-Monitor DPI v2、原生文件对话框与更新器），不引入重型第三方运行时或模型包。

## 3. 近期规划：`v0.3.0` — 顺手度与效率跃升

**版本目标**：消除日常高频操作中的交互摩擦，补齐原生离线 OCR 与托盘态反馈盲区，使 Koma 能够作为 Windows 日常唯一主力截图工具长期驻留。

建议按四个可独立验证的子里程碑推进：

### M1｜原位交互与标注顺手度
聚焦 `internal/app/overlay.go` 与 `internal/canvas/`：

- [x] **画布原地文字编辑**：点击画布后在落点直接浮出输入框，支持实时排版预览、换行与二次点击编辑，替代当前“先在二级栏输入再盖章”的两段式流程。
- [x] **原位标注二次编辑**：在桌面遮罩选区内支持选中已有矢量标注、拖拽移动位置与按 `Delete`/`Backspace` 删除，与 Studio 体验对齐。
- [x] **选区像素级键盘微调**：选区确立后支持方向键 1px 精细挪动与 `Shift + 方向键` 微调边线，便于精准贴合 UI 边界。
- [x] **原位转入工作台入口**：在原位工具栏增加「编辑」按钮与快捷键，直接调用已有 `OpenImageInEditorWithAnnotations` 将当前选区与矢量标注无损带入 Studio。
- [x] **取色多格式切换**：放大镜取色时按 `Shift` 在 `HEX` / `RGB` / `HSL` 间切换，按 `C` 复制当前格式并退出。

### M2｜托盘静置反馈与桌面贴图升级
聚焦 `internal/app/app.go` 与 `internal/app/pin.go`：

- [x] **全局悬浮轻提示（Toast HUD）**：解决主窗口关闭到托盘后 `NotifyToast` 静默丢失的问题；使用短生命周期透明 Liquid Glass 胶囊在屏幕底部短暂提示（取色成功、已复制、已保存等），展示结束后销毁窗口、不增加静置显存。
- [x] **延时截图悬浮倒计时**：托盘静置态触发延时截图时，在屏幕角落显示轻量 Liquid Glass 倒计时胶囊，支持 `Esc` 中途取消。
- [x] **贴图防误触右键菜单**：将贴图当前“右键直接关闭”调整为原生右键菜单（复制、保存、提取文字、鼠标穿透、旋转/翻转、重置 100%、关闭当前、关闭全部），防止误触丢失贴图内容。
- [x] **贴图鼠标穿透（Click-through）**：支持将半透明贴图设为鼠标穿透（基于 MyGo `IgnoreMouseEvents`），方便对照设计稿或代码抄写，并可通过托盘菜单或快捷键恢复交互。
- [x] **贴图效率补齐**：支持 `Ctrl+S` 快捷保存当前贴图，以及一键隐藏/恢复全部桌面贴图。

### M3｜配置闭环与保存效率
聚焦 `internal/app/settings.go` 与 `internal/app/editor.go`：

- [x] **长截图全局快捷键**：将 `StartLongCapture` 纳入设置面板的全局热键配置与托盘菜单展示。
- [x] **保存偏好与静默快速保存**：在设置中支持配置默认保存目录、默认导出格式（PNG / JPEG）与「快速保存（跳过保存弹窗直接按命名规则落盘）」选项，配合全局 Toast 反馈。

### M4｜原生离线 OCR 取字
聚焦 `internal/winapi/ocr_windows.go`、`internal/app/overlay.go` 与 `internal/app/pin.go`：

- [x] **Windows 原生 OCR 引擎封装**：通过纯 Go 调用 Windows 10/11 内置 `Windows.Media.Ocr`（WinRT COM），零外部模型下载、零安装包增量、非调用期零常驻内存。
- [x] **多入口统一接入**：
  - 原位截屏工具栏新增 `OCR` 按钮与快捷键，框选区域后直接识别文本；
  - 桌面贴图悬停操作栏支持一键识别贴图内文字；
  - Studio 工作台支持对当前图像执行 OCR。
- [x] **轻量文本结果浮层**：以 Liquid Glass 卡片呈现识别文本（支持一键复制全部或局部划词复制），优雅处理未安装对应系统语言包时的引导提示。

### `v0.3.0` 验收标准
- `go test -v -count=1 ./...` 全部通过，新增原地文字输入、OCR 封装、贴图菜单与快速保存的单元测试 / 无头 UI 回归测试。
- 托盘静置内存与显存占用相比 `v0.2.1` 无回归；Toast HUD 与 OCR 调用后资源完整释放并具备 GC 可达性验证。
- 关键界面变更完成 `KOMA_PREVIEW_DIR` 渲染截图视觉走查（浅色 / 深色 / 100% 全屏选区 / 长截图 / 设置页）。

## 4. 中期规划：`v0.4.0` — 采集底盘与工程演进

在 `v0.3.0` 补齐主力日常体验后，重点升级底层采集质量、复杂长截图场景与代码库可维护性：

- **HDR 显示器抓屏适配**
  - 当前 GDI `BitBlt` 在 Windows 11 开启 HDR 时会出现过曝/泛白；调研基于 DXGI Desktop Duplication 或 `Windows.Graphics.Capture`（WGC）的采集管线与 SDR 色调映射，保留 GDI 作为兼容回退。
- **滚动长截图复杂场景增强**
  - 优化高刷新率平滑滚动网页、极低纹理/暗黑纯色背景、局部嵌套滚动区域的帧对齐与防误判到达底部逻辑；按需评估横向滚动拼接。
- **历史记录轻量持久化（可选）**
  - 支持在设置中开启“跨重启保留最近截图”（写入应用数据目录并严格执行条数与总磁盘配额上限），关闭时保持当前纯内存隐私模式。
- **核心模块解耦重构**
  - 将体量较大的 `internal/app/editor.go`（设置/历史/帮助/画布）与 `internal/app/overlay.go`（输入/渲染/双层工具栏/放大镜）按职责拆分为独立文件，降低后续协作与维护成本。

## 5. 明确的非目标（Non-Goals）

为防止产品滑向臃肿，以下方向**明确不在规划内**：

- **装饰性美化套壳**：不重新引入渐变背景墙、模拟窗口阴影框等 Beautify 功能。
- **录屏 / GIF / 视频剪辑**：音视频编码与帧缓冲管线会显著破坏轻量化体积与内存边界。
- **账号体系、云同步与图床托管**：Koma 专注本地、离线、隐私友好的桌面工具体验。
- **重型内置 AI 模型或 WebView 插件生态**：不捆绑数十至数百 MB 的离线模型或浏览器运行时。

## 6. 变更与迭代节奏

- 每个子里程碑保持小步合入、独立可测，遵循先写不变量测试、再做视觉预览验证、最后全量构建验证的闭环。
- 路线图随版本发布同步更新，已完成项归档至 [CHANGELOG.md](../CHANGELOG.md) 与本文档第 2 节。
